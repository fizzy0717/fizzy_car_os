# Troubleshooting

## FIZZY OS does not appear in the Home app list
Check that installation completed and that the app manifest declares the HOME intent. Restart the device and check Android Settings > Apps > Default apps.

## The interface is slow
Test on a stationary device, close unused apps, and report the head-unit model, Android version, RAM and screen resolution. Do not remove unknown system packages.

## CarPlay, Bluetooth, radio or reverse camera stops working
Switch back to the factory launcher and restore any settings changed during testing. Do not uninstall vendor connectivity or vehicle-integration services.

## FIZZY OS crashes
Use Android Settings to select the factory launcher as the default Home app, then uninstall or report the issue.
