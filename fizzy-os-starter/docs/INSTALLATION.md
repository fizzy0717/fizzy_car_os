# Installation Guide

This guide will be expanded with screenshots after the first test APK is available.

1. Download the APK from the project's GitHub Releases page.
2. Keep the factory launcher installed.
3. Open the APK on the head unit and approve installation if Android requests it.
4. Open FIZZY OS once and review permissions.
5. Set FIZZY OS as the default Home app only after confirming how to return to the factory launcher.
6. Test while parked before normal driving use.

If your device blocks installation, check its Android security settings and manufacturer documentation. Do not install modified firmware or disable security protections just to install the launcher.
