# Restore the Factory Launcher and Uninstall FIZZY OS

1. Open Android Settings.
2. Find Apps, Default apps, then Home app (labels vary by manufacturer).
3. Select the factory/original launcher.
4. Confirm the factory Home screen works.
5. Open Settings > Apps > FIZZY OS > Uninstall.
6. Restart the head unit if required.

FIZZY OS is designed to be a normal user-installed launcher. It must not remove the factory launcher or system firmware. If the factory launcher is missing or cannot be selected, stop and consult the head-unit manufacturer before changing system packages.
