# FIZZY OS Design Guide

- Landscape-first automotive layout.
- Top status row: time, date, Wi-Fi name, Bluetooth device name, Settings.
- Left sidebar: up to four user-selected app shortcuts; All Apps stays fixed at the bottom.
- Main area: map occupies most of the center; right column contains Music, Weather and Waktu Solat.
- All Apps and Settings use the same restrained liquid-glass visual language.
- Do not display battery percentage in the top bar.
- Disconnected Wi-Fi/Bluetooth: show a dimmed icon only, hide the connection name.
- Prefer efficient translucent surfaces over expensive continuous blur effects.
